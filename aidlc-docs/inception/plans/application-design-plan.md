## Proposed Design Direction

- Use `web` as a Nuxt 3 application with auth pages, route middleware, a small auth composable, and an API client that sends credentials with HTTP-only cookie requests.
- Use `api` as a NestJS REST API with feature modules for auth, users, email, Prisma/database access, and configuration.
- Keep detailed auth business rules for Functional Design, while Application Design defines components, responsibilities, methods, and service boundaries.
- Keep SMTP behind an `EmailService` interface so provider details do not leak into auth orchestration.
